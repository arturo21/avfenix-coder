=== Descripción ===

WP Extreme Customize es el plugin definitivo para personalizar tu WordPress. Desarrollado por AVFDigital, este plugin te permite transformar completamente tu sitio según tu marca, con funcionalidades superiores a los plugins del mercado.

=== Características Principales ===

1. Login Customizer Extremo
   - Logo personalizado
   - Colores de marca
   - Fondo personalizado
   - Mensajes customizados
   - Redirecciones personalizadas

2. Admin Customizer
   - Barra de administración personalizada
   - Menú reorganizable
   - Ocultar elementos no deseados
   - Tema de administración personalizado

3. Email Customizer
   - Plantillas HTML personalizadas
   - Branding en todos los emails
   - Firma automática
   - Configuración por tipo de email

4. Seguridad Extrema
   - Limitador de intentos de login
   - 2FA opcional
   - Headers de seguridad
   - Ocultar información sensible

5. SEO Extreme
   - Meta tags avanzados
   - Open Graph personalizado
   - Schema.org integrado
   - Optimización de velocidad

6. Performance Extreme
   - Compresión de imágenes
   - Cache avanzado
   - Minificación de recursos
   - CDN integrado

=== Requisitos ===

- WordPress 5.8 o superior
- PHP 7.4 o superior
- Permisos de escritura en el directorio del plugin

=== Instalación ===

1. Descarga el plugin desde https://avfdigital.com/wp-extreme-customize
2. Ve a WordPress → Plugins → Añadir nuevo → Subir plugin
3. Selecciona el archivo .zip y haz clic en Instalar ahora
4. Activa el plugin desde la página de plugins
5. Configura cada módulo desde el menú WP Extreme Customize

=== Configuración Rápida ===

Una vez activado, accede a:
- WP Extreme Customize → Configuración General
- WP Extreme Customize → Login Customizer
- WP Extreme Customize → Admin Customizer
- WP Extreme Customize → Email Customizer
- WP Extreme Customize → Seguridad
